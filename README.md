A collection of Python-based scripts and visualizations demonstrating core **Control Theory** principles. Built as a visual study companion for students exploring dynamic systems and feedback control.

## Curriculum Alignment

The plots and simulations in this repository are organized around three courses from the **School of Electrical and Computer Engineering** at the **National Technical University of Athens (NTUA)**:

1. **Introduction to Automatic Control** - https://www.ece.ntua.gr/en/education/undergraduate/courses?selectedFlow=core&semester=5&courseId=3177
2. **Control Systems Design** - https://www.ece.ntua.gr/en/education/undergraduate/courses?selectedFlow=s&semester=6&courseId=3171
3. **Advanced Automatic Control Systems Techniques** - https://www.ece.ntua.gr/en/education/undergraduate/courses?selectedFlow=s&semester=7&courseId=3304
